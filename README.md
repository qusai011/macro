# 🚀 C++ Project with Discord Integration & Auto Updates

مشروع أداة بلغة C++ مدعوم بنظام **التحديثات التلقائية (Auto-Updater)** وربط المخرجات بـ **Discord Webhook**.

---

## 🌟 الميزات الرئيسية (Features)
- 🔄 **فحص التحديثات التلقائي:** يتم التحقق من آخر إصدار للمشروع مباشرة عبر GitHub API.
- 🔔 **تكامل مع Discord:** إرسال إشعارات فورية عند تشغيل الأداة أو حدوث تحديث.
- 📦 **دعم الملفات المتعددة:** إمكانية تنزيل وتثبيت أحدث النسخ والملفات التابعة تلقائياً.

---
